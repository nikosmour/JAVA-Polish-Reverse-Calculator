# JAVA Polish Reverse Calculator

This is a project I originally built during my university Java lessons some years ago.

## v0.1
Initial version of the project, as it was during the lessons.

## v1.0
- Fixed several mistakes from the original code  
- Added support for floating-point numbers  
- Fully working Polish Reverse Calculator (supports addition, subtraction, multiplication, and division with floats)  

### How it works
You enter the numbers and operations **in Reverse Polish Notation (RPN)**, meaning from right to left.  
Every time you finish typing a number, you press the **Enter** button to confirm it.  

If an error occurs, an error message will be shown. You can still continue entering numbers (though they won’t appear immediately on the display until confirmed).
